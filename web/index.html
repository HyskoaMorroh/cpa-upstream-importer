④ diff 预览与写回

只追加，不改现有行

写回前自动备份 —— CPA 的 PUT config.yaml 落盘用 O_TRUNC 且失败不回滚，备份是唯一保险。

CPA 地址不要填公网域名。公网入口在 Cloudflare 后面，管理端点的 PUT 会被挡成 403 error code 1010 —— 那是 CF 的拦截码， 不是 CPA 拒绝了配置。留空即走容器内服务名直连 （http://cli-proxy-api:8317），既绕开 CF 也不出公网。
这一步真正落盘。确认前核对每一处插入 —— priority 定错在分层隔离下 不是「略微靠后」，而是永远轮不到或完全取代现有顶层站。
